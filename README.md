# jwan-fisheye-city-cover

Jwan fisheye city-cover diptych Skill.

## Features

- Preserve the supplied city or street photo in the upper half of a vertical 9:16 image.
- Create a small centered fisheye-inspired illustrated portrait below.
- Use a coherent city-cover palette, clear identity continuity, and generous white space.

## Case

![Case 01](examples/case-01.png)

## Usage

Use `$jwan-fisheye-city-cover` followed by one city or street photo. Add the city, location, palette, or signature when needed.
